# Context

What a session reads before writing code: one FEFO graph over the generated
code vaults and the hand-written `docs/vault/` notes, then scoped `git grep`.
The graph indexes the vault; it does not replace it.

## FEFO graph

`fefo vault` builds `docs/vault/graph.json` from every `*.md` under
`docs/vault/` (generated and gitignored). Nodes: `file`, `heading`, `tag`,
`concept`, `repo` (note structure), `symbol` (`Name — path:line` definitions),
`module`, `route`, `commit` (code vault notes), and `location` for any note
line (cap 5000). Edges: `contains`, `tagged`, `references`, `documents`
(file → module), `touches` (commit → module), `used-by` and `imports`.

`fefo vault --changed` rebuilds the graph when a repo was regenerated, on
`--force`, or when `graph.json` is missing/older than a generated
`*-vault/*.md`. An unchanged refresh stays instant. `fefo graph --query <term>`
matches labels and paths case-insensitively (exact/prefix first, max 20) and
prints `kind<TAB>label<TAB>path:line`; it builds the graph once if missing.
`fefo graph` serves the same graph in a local viewer; `--out FILE` writes only
the HTML. Pure zsh, no external indexer or MCP server.

## Code vaults

`fefo vault [--changed] [--force] [NAME...]` generates one code vault per repo
with vault on (default; per-repo `vault=off`; `vault off` disables) at
`docs/vault/<slug>-vault/`, sourced from `git ls-files` only. `fefo init` runs
it; `fefo vault --changed` at session start skips repos whose `.stamp` equals
`HEAD` (prints `fefo: vault <name> unchanged`, ~0 cost; full regen prints
`fefo: vault <name> (<n> modules, <s>s)`); an optional OpenCode automation
(shell, every 30 minutes, `fefo vault --changed`) keeps vaults fresh on long
sessions. Output is generated and gitignored (`/docs/vault/*-vault/`).

Per repo:

- `00-INDEX.md`: `# <name> — code vault`; `repo <path> · stack <stack> · HEAD
  <short> · generated by fefo vault`; table `module | role | files | note`
  (`[[modules/<m>]]`); `## Entry points` (manage.py, */settings.py, */urls.py,
  main.*, package.json, pubspec.yaml, go.mod, cmd/*/main.go if tracked);
  `## Commands` (manifest test/lint/build/run non-empty); `## How to use`
  (index → module note → `path:line`; usages: `git -C <path> grep -n` inside
  the listed files).
- `modules/<m>.md`: `Role:`; `## Files`; `## Definitions` one line per file
  `path — Name:line, other:line` (top-level only: py `class|def|async def`;
  js/ts `export (default)?(function|class|const|interface|type) X`; dart
  `class|enum|mixin|extension`; go `func|type`); `## Routes` (Django
  `path()`/`re_path()`, DRF `router.register`, FastAPI `@app/@router.<verb>`,
  express `router.<verb>`); `## Models` (Django `class X(...Model...)` in
  `models*`); `## Imports from` / `## Imported by` (`[[modules/x]]`, counts);
  `## Used by` (imported names → files importing them, cap 10/name).
- `recent.md`: last 20 commits `hash date subject — module(nfiles), …`.

Modules are dirs with `apps.py` (depth ≤2) else top-level dirs holding source;
role: module `README.md` first line → `apps.py verbose_name` → `__init__.py`
docstring → `—`. Skipped: `tests/ test/ __tests__/ migrations/ venv .venv
node_modules dist build coverage __pycache__`, `test_*.py` `*_test.py tests.py
*.spec.* *.test.*`. Import edges come from one repo-wide `git grep`, not
per-file loops. Notes >1500 lines move Definitions into
`modules/<m>/<subdir>.md`.

## Knowledge notes

`docs/vault/` holds durable Markdown knowledge: `00-INDEX.md`, generated
`federation.md`, `repos/<slug>.md`, `decisions.md`, plus hand-written notes,
linked with `[[wikilinks]]` or relative links. Markdown is the source of
truth; `graph.json` is built from it. Run `fefo sync` after changing
`.fefo/workspace.zsh`. Never edit generated `*-vault/` folders by hand.

## Session flow

1. `fefo vault --changed`.
2. `fefo graph --query <symbol|module|route|note>` → kind, label, `path:line`.
3. Open the repo's `00-INDEX.md`, follow the module note, use its `path:line`.
4. Verify usages with `git -C <repo> grep -n` only inside the listed files;
   never grep a whole repo before reading its index.
5. Read `docs/vault/00-INDEX.md` for decisions, rules and past incidents;
   report what the graph or vault lacks.
